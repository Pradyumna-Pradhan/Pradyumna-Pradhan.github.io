# Pradyumna Pradhan — Academic Website

A simple, responsive, single-page academic website built with plain HTML, CSS, and JavaScript. It uses a conventional academic layout with a profile introduction, biography, research, publications, awards, and contact information.

## Preview locally

Open `index.html` in a modern web browser. No build tools or package installation are required.

## Files

- `index.html` — website content and metadata
- `styles.css` — responsive academic layout and styling
- `script.js` — mobile navigation, publication filters, and contact-form fallback
- `assets/pradyumna-pradhan.jpg` — supplied headshot
- `assets/Pradyumna_Pradhan_CV.pdf` — supplied CV linked from the website
- `assets/favicon.svg` — site icon
- `robots.txt` — crawler instructions
- `SETUP_GUIDE.md` — hosting, domain, contact form, SEO, and maintenance instructions

## Before publishing

1. Verify the publication titles, author lists, venues, years, and acceptance statuses against final publisher records.
2. Replace the placeholder Formspree endpoint in `index.html` to enable browser-based contact form submissions. Until then, the form opens the visitor's email application.
3. Add LinkedIn or ResearchGate links only after confirming the correct profile URLs.
4. Register a domain and update the site's metadata and search-engine settings as described in `SETUP_GUIDE.md`.
